# CARDIVIDE

https://kurehajime.github.io/cardivide/

CARDIVIDEは、COM対戦できるカードゲームです。

両プレイヤーの間にクリーチャーを横一列に並べ、相手の戦列へ自分のカードを差し込んで部隊を分断します。大きな部隊を育てるか、複数の小さな部隊で別々の戦線を作るか。毎ターン、どの部隊を動かすかを選びながら、相手プレイヤーを攻めます。

## 勝利条件

相手プレイヤーのHPを **0以下** にすると勝利です。

## ゲームの特徴

CARDIVIDEの戦場は、両プレイヤーを結ぶ一本の列です。

```text
[あなた][自軍][自軍][敵軍][自軍][敵軍][相手]
```

カードのための空きマスはありません。  
新しいクリーチャーは、プレイヤーやカードの隣、または二枚のカードの間へ差し込まれます。

相手の連続した部隊の間へ自分のカードを置くと、相手の部隊は二つに分かれます。

```text
変更前
[敵][敵][敵]

中央へ自軍を差し込む
[敵][自軍][敵][敵]
```

分断された部隊は、それぞれ別の**グループ**として扱われます。  
間にいるカードが場を離れ、同じプレイヤーのカード同士が再び隣り合えば、一つのグループへ戻ります。

## カードの種類

### クリーチャー

クリーチャーは戦場へ召喚し、グループを作って戦います。

カードには主に次の数値があります。

- **コスト**：召喚に必要なマナ
- **攻撃力**：攻撃するときに加える力
- **防御力**：破壊されるまでに必要な攻撃
- **進軍**：何枚のカードを越えて召喚できるか
- **属性**：赤・青・緑のいずれか

能力を持つカードは、カードに書かれた文面に従います。

### 魔法

魔法は、捨て札の利用、回復、移動、追加マナ、直接ダメージなどを行います。

効果をすぐに解決する魔法と、一定期間だけ場に残る魔法があります。

## ターンの流れ

自分のターンは、次の順番で進みます。

### 1. キープアップ

- 手札が5枚になるようにカードを引きます。
- 2マナを得ます。

### 2. メイン

マナがある限り、好きな順番で行動できます。

- クリーチャーを召喚する
- クリーチャーの起動型能力を使う
- 魔法を使う
- 手札を1枚まで捨てる


### 3. 戦闘

自分のグループを一つ選び、相手側へ攻撃できます。

攻撃しないこともできます。

### 4. クリーンナップ

- 手札が6枚以上なら、5枚になるまで捨てます。
− 使わなかったマナは、通常は次のターンへ持ち越されます。


## 召喚と進軍

クリーチャーを召喚するときは、カードのコストと同じだけマナを支払います。

基本的には、自分のプレイヤーや自分のクリーチャーの近くへ召喚します。  
**進軍**の数値が高いクリーチャーは、相手方向へカードを越え、戦場の奥深くへ入り込めます。

進軍を使うと、次のようなことができます。

- 敵の前衛を越え、後方へ入り込む
- 敵グループを途中で分断する
- 相手プレイヤーの近くへ新しいグループを作る
- 離れた味方へ援軍を送る

選択できる召喚位置はゲーム画面に表示されます。

## グループ

同じプレイヤーのクリーチャーが連続しているひと塊を、**グループ**と呼びます。

```text
[自軍][自軍] ＝ 1グループ

[自軍][敵軍][自軍] ＝ 自軍2グループ、敵軍1グループ
```

一つの大きなグループは、高い攻撃力をまとめやすくなります。  
複数のグループを作ると、相手へ異なる場所から圧力をかけられます。

ただし、1ターンに攻撃できるのは一つのグループだけです。  
どの戦線を動かすかが、毎ターンの重要な選択になります。

## 戦闘

攻撃するグループの**攻撃力をすべて合計**します。

その攻撃を、相手グループの先頭から順番に当てます。  
ここでいう先頭とは、相手プレイヤーに近い側です。

攻撃がクリーチャーの防御力以上なら、そのクリーチャーを破壊します。  
余った攻撃力は、次のクリーチャーへ続いていきます。

### 例

攻撃グループの合計攻撃力が8。  
防御側に、防御力2と防御力4のクリーチャーが並んでいるとします。

```text
攻撃8
→ 防御2を破壊。残り6
→ 防御4を破壊。残り2
```

そのグループが相手プレイヤーを守っていた場合、残った攻撃力は相手プレイヤーへ届きます。

プレイヤーは常に**バリア2**を持っています。  
プレイヤーへ届いた攻撃は2点減らされ、残った分だけHPを減らします。

上の例では残り2がバリアで止まり、HPへのダメージは0です。  
攻撃力が9なら3点が届き、バリアを引いた1点がHPへのダメージになります。

## 破壊とマナの返還

破壊されたクリーチャーは捨て札へ置かれます。

通常、破壊されたクリーチャーのコストの半分が、切り捨てで持ち主へ返ります。

```text
コスト2 → 1マナ
コスト4 → 2マナ
コスト5 → 2マナ
```

《消滅》など、返還を変更する能力がある場合はカードの文面を優先します。

## 最初に覚える三つのこと

### 1. カードは「置く」のではなく「差し込む」

どのカードの間へ召喚するかで、グループの形が変わります。  
数値だけでなく、位置が重要です。

### 2. 分断すると相手の攻撃を迷わせられる

敵軍の間へ入り込むと、相手は複数のグループから攻撃先や防衛先を選ばなければなりません。

### 3. 攻撃できるのは一部隊だけ

強いグループを一つ作るか、小さなグループを複数残すか。  
盤面全体を見て、今動かす戦線を選びましょう。
